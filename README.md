#  مشروع تحليل بيانات المبيعات والإيرادات – Excel Dashboard

هذا المشروع يهدف إلى تحليل بيانات المبيعات من متجر دولي للفترة بين **2011 إلى 2014**، باستخدام **Excel**، ويتضمن **لوحة تحكم تفاعلية (Dashboard)** وتقرير شامل يحتوي على التوصيات والاستنتاجات.

---

##  محتوى المشروع:

-  تحليل المبيعات حسب الفئة، القطاع، المدينة، والمنطقة الجغرافية.
-  حساب متوسط مدة الشحن وتحليل أداء وسائل الشحن المختلفة.
-  تحديد المنتجات والعملاء الأعلى قيمة.
-  بناء **تقرير احترافي** يحتوي على أبرز النتائج.
-  تصميم **Dashboard تفاعلي** يعرض المخرجات بطريقة مرئية احترافية.

---

## الملفات المرفقة:



| `Sales_Report.docx`    | تقرير مفصل يحتوي على التحليلات والاستنتاجات. |
